# Viable

Viable is a local-first marketability operating system for founders, maintainers, products, public repositories, and small teams.

Its purpose is to help answer a practical question: **what should we do next to make this product more viable, and what evidence supports that decision?**

Viable connects product truth, ICP discovery, marketability assessment, external signals, campaigns, repository readiness, governed activation, outcomes, and learning through one explicit operating model.

## The operating loop

```text
Product truth
  -> ICP hypotheses
  -> marketability assessment
  -> external evidence and signals
  -> positioning, offers, and experiments
  -> canonical campaign assets
  -> destination variants
  -> named review
  -> activation
  -> delivery and outcome evidence
  -> retrospective and learning
  -> next reversible action
```

Events were the original starting point, but Event Intelligence is now only one bounded signal source. Website monitoring, repository evidence, social/community signals, search, analytics, relationships, sales, and other adapters fit around the same evidence and governance model.

## Current maturity

Viable is pre-release. Its implemented core is substantial and automatedly validated, but public source availability is not the same thing as a supported end-user product release.

For authoritative current capability and remaining release gates, see [Current implementation state](https://github.com/MythologIQ-Labs-LLC/Viable/blob/main/docs/status/current-state.md).
